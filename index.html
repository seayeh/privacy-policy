引言

「智能查房」（App Store 亦可能显示为 SmartWardRound，以下简称「本应用」）是一款面向医疗从业者的病历书写与查房辅助工具。 开发者叶海波（以下简称「我们」）尊重并保护您的隐私。

本政策说明我们在您使用本应用时如何处理相关信息。患者病历与查房数据默认仅保存在您的设备上，我们不会将病历上传至自有服务器。 仅在您主动使用相关功能时，才可能将经脱敏处理的内容发送至您自行选择配置的第三方在线服务，或发送至您在同一局域网内指定的电脑端接收程序。

本应用不用于广告追踪，不出售患者或用户数据，不包含第三方广告、统计或崩溃上报组件。

一、我们处理的信息

1.1 信息类型

  • 患者与临床信息：您录入的床号、姓氏、性别、年龄、住院号/病历号、诊断、入院/出院信息、查房记录、病程与各类文书内容、辅助检查摘要等。
  • 您的账号资料：工号、姓名、科室、职称、电话、头像等（加密保存在本机，用于登录校验与登录后的工作区展示）。
  • 登录相关偏好：您是否勾选「记住当前账号」（仅控制未登录时是否在首页预留账号展示信息；不保存密码）。
  • 语音与图像：您在查房、语音转写或病案录音转写时主动录制的音频；您通过相机或相册选择的床头卡、腕带、检验报告等图片（用于文字识别）。
  • AI 相关配置：您在「设置 → AI Key 管理」中自行填写的大模型访问密钥（仅保存在本机，不上传给我们）。
  • 病案录音转写配置：若您使用病案转写功能，可配置第三方 ASR 凭证（如阿里云语音识别 AccessKey）或启用 Whisper 本地识别；凭证仅保存在本机。
  • 入院处理与书写模板：您自定义的入院处理快速模板、入院记录书写模板及通用的病程模板（加密保存在本机）。
  • 应用偏好：语言、界面与模板设置、局域网发送目标地址、「记住当前账号」选项、隐私政策与第三方 AI 数据共享同意记录等。

1.2 存储位置

患者病历与查房数据主要保存在您的 iPhone/iPad 本机。我们不会运营云端病历库，也不会通过本应用将病历同步至 iCloud。

  • 结构化病历、查房会话与文书正文保存在本机应用数据区。
  • 文书草稿、账号资料及部分敏感字段采用本机加密方式保存；登录密码摘要与加密访问密钥保存在系统钥匙串中。
  • 病案录音转写的音频文件、转写结果及 AI 整理稿临时保存在本机，您可主动删除或导出。
  • 您导出的 PDF、Word 等文件在分享前暂存于本机，仅在您使用系统「分享」时离开设备。
  • 若您开启了 iPhone 整机备份或 iCloud 备份，备份内容是否包含本应用数据由 Apple 与您的系统设置决定，这不等于我们将病历上传至自有服务器。

二、本机账户与登录

本应用使用本机账户区分不同使用者，不涉及联网注册、云端登录或微信 / Apple 账号等第三方登录。

  • 您在本机创建账号并设置工号、姓名与登录密码；密码经加密摘要后保存在系统钥匙串，不经我们服务器验证，不以明文保存。
  • 账号完整资料（含头像、科室、职称、电话等）加密保存在本机，用于登录校验；退出登录不会删除这些资料及患者/查房数据。
  • 未登录时，应用首页显示账号密码登录界面。默认不预留上次账号、头像或姓名；您可勾选「记住当前账号」，在下次成功登录后若再次退出，首页将预留工号与资料展示，但仍须输入密码。
  • 退出登录后，「个人账号管理」与设置页账号区不显示上次登录的账号资料；是否仅在首页预留账号，由「记住当前账号」选项决定。
  • 不同账号下的患者与查房记录在设备上分别展示；登录后仅显示与当前账号关联的数据。
  • 退出登录：在「设置 → 退出登录」或「个人账号管理」中操作。仅结束当前会话，保留本机加密账号资料、密码摘要及关联的患者与查房记录。
  • 修改密码：登录后在「个人账号管理」中验证当前密码后设置新密码。
  • 删除账号：仅在「设置 → 个人账号管理 → 删除账号与本地资料」中提供。操作前会警示说明，并需通过面容 ID、触控 ID 或设备密码确认。此操作不可撤销，将永久删除本账号及关联的全部患者病历、查房医嘱、辅助检查、病程记录、各类文书、病案转写记录等临床数据，并清除本机账号资料、密码与「记住当前账号」偏好。
  • 清空临床数据（保留账号）：在「设置 → 数据与安全 → 清空当前账号全部临床数据」中提供（需设备验证）。仅清除患者列表、查房记录与关联的病程文书，不删除本机账号资料。
  • 清空全部患者、管理 AI 密钥、导出数据快照、删除账号、清空临床数据等敏感操作，需通过面容 ID、触控 ID 或设备密码确认。

三、网络与对外传输

以下情况均须您主动使用相关功能才会发生，我们无自有后端存储病历。

3.1 第三方在线服务（加密互联网连接）

当您在「AI 问答」「生成病程」「AI 整理病案转写」「智能生成入院记录/首次病程/出院记录」等功能中使用 AI，或在医患录音转写后选择 AI 整理文书时，本应用会将经脱敏处理的文字内容，通过加密连接发送至您在「AI Key 管理」中自行配置的大模型服务，例如：

  • DeepSeek、阿里云百炼、讯飞星火、智谱 GLM 等（具体以您选择的提供商为准）
  • 用于生成或整理临床文书、回答医学参考问题、生成病程模板的参考内容

发送前，我们会尽量去除或替换患者姓名等直接标识信息；住院号等编号仍可能出现在您提交的文本中。 上述服务由相应第三方运营，其数据处理规则请查阅该服务商的隐私政策。 访问密钥仅由您填写并保存在本机，我们不会收集或存储您的密钥。

3.2 医学文献检索

当您使用文献参考功能时，本应用可能向 PubMed、Europe PMC 等公开医学数据库发送经脱敏的诊断检索词，以获取文献摘要与链接。这些机构对其收到的请求有各自的隐私政策。

3.3 语音与图像识别

  • 查房语音转写：语音识别在您的设备上完成，音频不会上传至我们的服务器。
  • 医患录音转写：默认使用 Apple 系统语音识别在设备上完成；您也可在「设置 → 病案转写」中选择Whisper 本地识别（应用内集成，完全离线），或配置第三方 ASR 服务（如阿里云语音识别）以提高准确率。若选择第三方 ASR，音频文件和文字内容将通过加密连接发送至您指定的服务商。凭证仅保存在本机。
  • 报告与床头卡图片识别：文字识别在您的设备上完成，图片默认不会上传至我们的服务器或第三方 OCR 云服务。
  • 增强识别包（可选）：您可在「设置 → 病人录入 → 增强本地识别包」中主动下载更新包；下载时应用会连接互联网获取识别资源并保存到本机，仅用于提升本地识别效果。

3.4 发送到电脑（可选，局域网）

您在文书或转写界面使用「发送到电脑」，并在设置中填写目标电脑地址后，本应用会在同一 Wi‑Fi/热点局域网内，将经脱敏的正文发送至您指定的接收程序，便于在电脑上粘贴使用。

  • 该功能不会经过我们的服务器。
  • 连接在局域网内进行；请仅在您信任的网络环境中使用。
  • 电脑端接收程序由您或所在机构自行安装与维护。接收端如何保存、转发或处理收到的文字，由部署方自行负责，请您遵守机构的信息安全规定。

3.5 网络连接弹性与自动重试

为提升网络不稳定环境下的使用体验，本应用在与 AI 服务或文献检索服务的通信中实现了自动重试与退避策略：当网络临时中断或服务暂时不可用时，应用会在有限次数内自动重试请求，并在重试间隔中逐步延长等待时间，以减少对第三方服务的冲击。 此过程不涉及额外数据收集，所有重试均使用原请求的同一份脱敏内容。

3.6 我们不会做的事

本应用不会通过远程推送、蓝牙或广告网络收集或使用您的个人信息；不会将病历上传至我们自有服务器。

四、第三方服务说明

除 Apple 系统提供的基础能力（如相机、麦克风、通知、锁屏进度展示、系统语音识别等）外，本应用不包含独立的第三方广告或统计分析组件。

您主动启用 AI、文献检索或病案转写时，可能使用的第三方在线服务包括：

  • 大语言模型服务（DeepSeek、阿里云百炼、讯飞星火、智谱 GLM 等，以您的配置为准）
  • 公开医学文献数据库（PubMed、Europe PMC 等）
  • 第三方语音识别服务（如阿里云语音识别，以您的配置为准）

请在使用前阅读相应第三方的服务条款与隐私政策。

五、设备权限

本应用可能在以下场景请求系统权限：

  • 相机：拍摄床头卡或腕带以识别床号等信息
  • 相册：选择检查报告等图片进行识别导入；选择已有音频文件导入病案转写
  • 麦克风：查房语音转写、病案录音转写
  • 语音识别：将口述内容转为文字
  • 面容 ID / 设备密码：敏感操作前确认本人（含删除账号、清空临床数据等）
  • 本地网络：「发送到电脑」功能
  • 通知：提醒您处理未完成的医嘱记录（通知中不包含患者姓名）
  • 锁屏与灵动岛进度：后台生成文书时在锁屏展示进度（仅显示床号，不显示姓名）

本应用不会请求访问健康数据、定位、通讯录、蓝牙等权限。

六、患者信息与隐私保护

  • 您可在本机录入患者相关信息以完成临床文书工作；界面以姓氏尊称展示（如「张先生」），录入时仅需填写《百家姓》范围内的单姓或复姓，不要求填写全名。
  • 向 AI 或局域网发送内容前，我们会尽量去除姓名等直接标识；您仍应在分享或发送前自行核对内容。
  • 检验报告等通过拍照/相册识别时，识别结果在保存前提供复核界面，供您确认或修改。
  • 后台生成文书时，锁屏与灵动岛仅显示床号。
  • 切换至其他应用或长时间离开后，界面可能显示隐私遮蔽，并在返回时要求验证，以降低他人窥视风险。

七、数据安全

  • 病历与敏感草稿在本机加密保存；系统钥匙串用于保护您的 AI 密钥、第三方 ASR 凭证、登录密码摘要与加密材料。
  • 与 AI 服务商、第三方 ASR 服务的通信采用加密连接。
  • 在检测到设备存在严重安全风险时，可能限制临床功能的使用，以保护数据安全。
  • 复制临床正文时，系统剪贴板会设置较短的有效期，以降低内容长时间残留的风险。
  • 应用在发生网络切换（如 Wi‑Fi 与蜂窝数据切换）时主动关闭旧连接并重建安全连接池，防止因底层连接失效导致的加密会话泄露。

八、导出、删除与留存

您可以通过以下方式管理数据：

  • 导出加密备份：设置 → 数据与安全 → 导出加密 JSON 快照
  • 导出 PDF / Word：各文书页面的分享功能
  • 删除单个患者：首页在院列表左滑删除
  • 清空全部患者：首页在院列表右上角（需设备验证；不删除本机账号）
  • 清空当前账号全部临床数据：设置 → 数据与安全 → 清空临床数据（需设备验证；保留本机账号资料）
  • 清除缓存 / 加密草稿 / 病案转写缓存：设置中相应选项
  • 退出登录：设置 → 退出登录（保留加密账号资料、密码摘要及患者与查房记录；未登录界面默认不展示账号资料）
  • 记住当前账号：首页登录时可选；勾选后退出登录时首页可预留工号与头像等，但不保存密码
  • 删除账号：设置 → 个人账号管理 → 删除账号与本地资料（需警示确认与设备验证；永久删除本账号及关联全部临床数据）
  • 卸载应用：将删除本机上的全部应用数据

已向第三方 AI 服务、第三方 ASR 服务发送的内容，我们无法代为删除；您可在该服务商处按其政策处理，并可在本应用中清除或更换 AI 密钥及 ASR 凭证。

九、儿童隐私

本应用面向医疗专业人员，并非面向 13 周岁以下儿童设计，也不会故意收集儿童个人信息。 若您认为有儿童在未授权情况下使用了本应用，请通过下方邮箱联系我们。

十、医疗免责

本应用为病历书写辅助工具，不提供诊断、处方或急诊服务。 AI 生成内容仅供参考，不替代执业医师的判断。出现危急病情请立即就医。
