应用简介

智能查房（App Store 亦可能显示为 SmartWardRound）是一款面向医疗从业者的 住院查房与病历书写辅助工具。患者与查房数据默认仅保存在您的设备上； AI 功能需您自行配置第三方大模型 API Key。

本应用采用「一机一软件」模式，无需注册账号或登录，打开即用。 所有患者与查房数据直接保存在本设备上，开发者不运营云端病历库。

主要功能

📋 病历文书

入院记录 首次病程记录 入院医患沟通 综合病程记录 阶段小结 出院记录 转出记录 术前讨论 术前小结 手术知情同意书 手术记录 术后首次查看 特殊治疗知情同意书 住院超30天讨论记录 医患对话→综合病史

🤖 AI 辅助

  • 多模型支持：DeepSeek、阿里云百炼、讯飞星火、智谱 GLM — 您自行配置 API Key
  • 智能路由：按任务类型自动选择最优模型，支持双模型协作（DeepSeek 起草 + GLM 结构化）
  • AI 文书生成：入院记录、病程、手术文书等一键智能生成
  • 医患对话结构化：将医患对话自动整理为主诉、现病史、既往史等综合病史
  • AI 问答：医学参考问答，支持文献检索（PubMed / Europe PMC）

🎤 语音输入

  • 查房语音转写医嘱：Apple 系统语音识别，设备端完成，音频不上传
  • 文书场景语音输入：搭配第三方键盘（如豆包输入法）实现流式语音转文字，不保存本地音频

📷 OCR 文字识别

  • 入院记录 OCR 导入：拍摄纸质病历 → 本地识别 → 脱敏 → 自动分章填入入院记录
  • 辅助检查导入：拍摄检验报告、影像报告 → 结构化提取异常指标与参考范围
  • 全程本地处理：图片不离开设备，OCR 运行在隔离沙箱中
  • 增强识别包（可选）：离线下载 ML 模型，提升化验单等表格类识别效果

📊 查房管理

  • 白板查房：按床位滑动，医嘱勾选，语音捕获，手写涂鸦
  • 每日待办：自动生成待办清单，17:30 未完成提醒
  • 病程回填：既往日期病程补录，智能匹配在院时段
  • 查房历史：按日期回顾，批量生成病程，合并导出

🔐 隐私与安全

  • 病历与草稿 AES-256-GCM 本机加密保存
  • AI 密钥保存在系统 钥匙串
  • 向 AI 发送内容前经 Safe Harbor 脱敏（去除姓名、机构名等）
  • 面容 ID / 触控 ID / 设备密码保护敏感操作
  • 锁屏与灵动岛 仅显示床号，不显示姓名
  • 临床剪贴板 2 分钟自动过期
  • 越狱设备拒绝运行

📤 导出与分享

  • 单篇文书导出 PDF / Word
  • 多类文书合并导出为一份 Word 文档
  • 加密 JSON 快照：全量数据备份与恢复
  • 发送到电脑：局域网内一键发送脱敏正文到电脑端接收程序

🎨 个性化

  • 文书模板：拍照学习现有模板，AI 学习结构与风格
  • 科室骨架：按科室自定义病程大纲
  • 快速模板：入院处理、体格检查、辅助检查预设
  • 写作教练：多轮 AI 对话微调临时写作指令
  • 多语言：中文、English、日本語、Deutsch、한국어
