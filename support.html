常见问题

如何配置 AI 功能？

打开应用 → 设置 → AI Key 管理，选择服务商（DeepSeek、阿里云百炼、讯飞星火、智谱 GLM 等），填写 Endpoint、Model 与 API Key 并保存。首次向第三方发送数据前，应用会弹出数据共享说明并要求您明确同意。

本机账号：登录、退出与删除有什么区别？

本应用使用本机账号区分使用者，不涉及联网注册或第三方登录。账号资料（工号、姓名、科室、职称、电话、头像等）与登录密码均加密保存在您的设备上。

  • 首次使用 / 登录：未登录时，首页显示账号密码登录界面。若本机已有账号资料，会自动展示头像、姓名、科室，您通常只需输入密码即可登录。
  • 创建本地账号：在登录页底部点击「创建本地账号」，或在「设置 → 个人账号管理」中填写工号、姓名、科室等信息并设置登录密码（至少 6 位）。创建成功后将自动登录。
  • 退出登录：「设置 → 退出登录」，或在「设置 → 个人账号管理 → 退出登录」。仅结束当前登录状态，不会删除本机账号资料，也不会删除与该账号关联的患者与查房记录。再次输入账号与密码登录后，可恢复显示原有资料与患者列表。
  • 修改密码：登录后进入「设置 → 个人账号管理」，在「修改密码」中验证当前密码并设置新密码。
  • 删除账号：仅在「设置 → 个人账号管理 → 删除账号与本地资料」中提供。操作前会弹出警示说明；确认后需通过面容 ID、触控 ID 或设备密码验证。此操作不可撤销，将永久删除本账号及关联的全部患者病历、查房医嘱、辅助检查等临床数据，并清除本机账号资料与密码。
  • 删除全部患者数据（不删账号）：首页在院患者列表右上角垃圾桶按钮（需设备验证）。仅清空患者列表，不删除本机账号资料。

数据存在哪里？会上传到开发者服务器吗？

病历与查房数据默认仅存本机，开发者不提供云端病历库。仅在您主动使用 AI、文献检索或「发送到电脑」等功能时，才可能将经脱敏的内容发送至您配置的第三方服务或局域网电脑。详见隐私政策。

应用无法使用 AI / 连接测试失败？

  • 确认已在 AI Key 管理中保存有效 API Key，且 Endpoint 与 Model 与服务商控制台一致。
  • 确认设备可访问互联网，且未被机构网络拦截 HTTPS。
  • 若更换服务商或 Endpoint，需重新确认第三方 AI 数据共享同意。
