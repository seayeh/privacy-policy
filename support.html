Smart Ward Round (SmartWardRound)
开发者：叶海波
最后更新：2026-10-03

本应用是一款面向医疗从业者的住院查房、门诊书写与病历辅助工具。患者、查房与门诊草稿默认仅保存在您的设备上；AI 功能需您自行配置第三方大模型 API Key。支持入院记录、首次病程、入院沟通、综合病程、阶段小结、出院记录、转入记录、转出记录、门诊病历、术前文书套件（术前讨论/术前小结/手术知情同意书/手术记录/术后首次查看等）、特殊治疗同意书、住院超30天讨论记录，以及医患对话结构化整理为综合病史等多种文书类型。

常见问题

如何配置 AI 功能？

打开应用 → 设置 → AI Key 管理，选择服务商（DeepSeek、阿里云百炼、讯飞星火、智谱 GLM、月之暗面 Kimi 等），填写 Endpoint、Model 与 API Key 并保存。首次向第三方发送数据前，应用会弹出数据共享说明并要求您明确同意。进入该页前需要设备密码或生物识别验证。

应用内置了模型路由机制：系统会按任务类型（如病程书写、AI 问答、文书生成等）自动选择最合适的模型。您也可以在 AI Key 管理中为各任务类型分别指定偏好的模型。

如何使用语音输入？

本应用提供三种语音相关方式：

  • 查房语音转写医嘱：在查房界面使用 Apple 语音识别。设备支持端侧识别时在本机完成；不支持时，音频可能由 Apple 处理。开发者不接收这段音频。
  • 录音转文书：可现场录音，或导入 mp3 / wav / m4a / ogg。应用会在本机保存一份可回放、可删除的录音副本。识别使用 Apple 语音识别，未强制仅在设备端完成，音频可能由 Apple 处理。整理成文书时，文字会发往您配置的大模型。
  • 第三方键盘：仍可搭配豆包输入法等键盘，在文本框里语音转文字。该方式不由本应用保存音频，请同时阅读该键盘的隐私政策。

需要注册开发者账号吗？本机资料是什么？

不需要向开发者注册或登录，也没有微信登录或“通过 Apple 登录”。请打开 设置 → 本机资料设置，填写昵称、病历书写环境（中西医结合或西医）和科室。这些资料只保存在本设备，用于匹配文书模板，不会上传。

App Store 正式版自首次打开起可免费试用 30 天。试用结束后，需在 设置 → 订阅与会员 中购买或恢复有效会员。付款、取消和退款由 Apple 处理，卸载应用不会自动取消订阅。

数据存在哪里？会上传到开发者服务器吗？

病历、查房与门诊草稿默认仅存本机，开发者不提供云端病历库，也不接收会员收据。仅在您主动使用 AI、文献检索、CpubMed、专用化验单 OCR，或使用录音转文书 / 启动页资讯时，才可能按隐私政策向相应第三方发送内容。

如何使用入院处理快速模板？

您可以在「设置 → 入院处理模板」中预定义常用的入院处理方案和诊疗计划要点。在录入患者时，可一键套用模板，减少重复输入。

  • 支持创建、编辑、删除自定义模板。
  • 模板加密保存在本机，不会上传。

如何进行病程回填（Backfill）？

如果在查房当日未能及时完成病程记录，可通过「回填病程」功能将既往日期的病程补录到对应的查房会话中。系统会智能匹配查房日期与患者的在院时段，生成包含正确日期的文书框架。

应用无法使用 AI / 连接测试失败？

  • 确认已在 AI Key 管理中保存有效 API Key，且 Endpoint 与 Model 与服务商控制台一致。
  • 确认设备可访问互联网，且未被机构网络拦截 HTTPS。
  • 首次向第三方发送数据前需完成一次数据共享同意；该同意覆盖已列出的模型服务。
  • 如网络环境不稳定，应用会自动重试请求；如持续失败，请检查网络连接后重试。

如何使用术前文书套件？

在患者详情页的「术前准备」区域，可创建和管理以下手术相关文书：

  • 术前讨论：记录术前科室讨论意见与手术方案。
  • 术前小结：汇总术前诊断、手术指征与准备情况。
  • 术者术前查看患者：主刀医师术前访视记录。
  • 手术审批表：手术级别与审批意见。
  • 手术知情同意书：向患者/家属说明手术风险并取得同意。
  • 手术记录：术中操作与发现的详细记录。
  • 术后首次查看患者：术后首次查房记录。

每项文书均支持 AI 辅助生成，也可手动编辑。生成内容需经执业医师审核确认。

如何使用特殊治疗同意书？

在患者详情页可创建特殊治疗知情同意书，用于记录需向患者/家属告知的特殊治疗（如输血、有创操作、特殊用药等）并取得同意。支持填写治疗操作名称、操作步骤说明与补充备注；AI 可根据患者病情辅助生成同意书草稿。

如何使用住院超30天讨论记录？

对于住院时间超过30天的患者，应用提供住院超30天讨论记录功能。在患者详情页可创建多段讨论记录，每段包含讨论日期、参与人员、讨论内容与结论。AI 可辅助生成讨论记录草稿。

如何使用医患对话结构化（综合病史）？

在入院记录编辑页面的「高级模式」中，可将医患对话内容经 AI 结构化整理为综合病史并自动回填。支持两种入口：

  • 高级模式直接输入：在「综合病史讲述」区域点击「从医患对话结构化填充」，粘贴或通过第三方键盘语音输入医患对话内容，AI 将自动整理为主诉、现病史、既往史、个人史、月经婚育史、家族史等结构化字段。
  • 场景录音转写模式：在入院记录的场景录音转写模式下完成对话清洗后，点击「整理为综合病史」即可直接使用已清洗的对话内容进行结构化整理。

生成的综合病史将自动回填至高级模式的「综合病史讲述」区域，可继续手动编辑。AI 生成内容需经执业医师审核确认。

如何合并导出患者全部文书？

在患者详情页或出院患者文书列表中，可使用合并导出功能将患者的多类文书（入院记录、病程、阶段小结、出院记录、手术文书、住院超30天讨论记录等）合并为一份 Word 文档或纯文本预览。您可在导出前勾选需要包含的文书类型。

什么是增强本地识别包？

增强本地识别包是可选组件，内含开源百度 Paddle OCR模型，用于提升辅助检查、化验单等表格类图片的识别效果。安装前会请您确认。当前公开发布版本从应用内置模型安装到本机，安装过程不联网。患者图像仍在设备本地识别，不会因该包上传。包体可能占用数十至数百 MB；可在设置中删除并恢复默认识别。

这与专用“化验单 OCR”不同。后者仅在您主动选择并同意后，才可能把所选原图经您配置的 HTTPS 代理发往阿里云 OCR。

如何把文书发送到电脑？

将 BLE Input Bridge 插入电脑 USB 口，在文书页点按「一键蓝牙传输」。接收器会像键盘一样，把您确认的纯文本输入到当前光标处，电脑无需安装本应用插件。可在 设置 → 蓝牙发送到电脑 中查看连接说明。

  • 仅在您点按并确认后发送。OCR 脱敏核阅期间不能发送。
  • 蓝牙链路多为近场明文，请只在工位使用，发完可拔出接收器。
  • 当前版本不提供局域网 / Wi‑Fi 发送。

如何使用门诊工作站？

在设置中打开门诊工作站。它独立于住院查房：可自选科室专业，也可沿用本机资料。填写主诉或诊断后，可生成门诊病历草稿，再复制或通过蓝牙发送到 HIS。草稿保存在本机。生成内容须由接诊医师审核后再使用。

如何启用 CpubMed 中文文献库？

这是可选项。打开 设置 → CpubMed 中文文献库（进入前需设备验证），在 CPubMed-Wiki 申请个人 API 签名，粘贴保存并做连接测试。启用后，文献检索会把经脱敏的检索词和该签名发往 CpubMed。签名保存在本机钥匙串。不需要时请在同一页面清除签名并停用。

启动页为什么会出现文献标题？

「设置 → 启动页每日推送」默认开启。应用会按当前科室向 PubMed 查询近期题名，不发送患者信息。可随时关闭。关闭后不再为该功能访问 PubMed。

试用结束或提示需要会员怎么办？

  • 打开 设置 → 订阅与会员，购买月度、季度、半年、年度或终身会员，或点「恢复购买」。
  • 请使用购买时的同一个 Apple ID。
  • 价格以 App Store 返回为准。取消与退款请在 Apple 的订阅管理中操作。
  • 开发或 TestFlight 测试安装可能不要求购买；App Store 正式版在试用结束后需要有效会员。
